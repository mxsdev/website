# mxs.dev

Personal site. Astro static site published to GitHub Pages at [www.mxs.dev](https://www.mxs.dev).

## Commands

| Command           | Action                          |
| :---------------- | :------------------------------ |
| `npm install`     | Install dependencies            |
| `npm run dev`     | Dev server at `localhost:4321`  |
| `npm run build`   | Build to `./dist/`              |
| `npm run preview` | Preview production build        |

## Deploy

Pushes to `main` run `.github/workflows/pages.yml`, which builds Astro and deploys to GitHub Pages (`www.mxs.dev` / `mxs.dev`).
